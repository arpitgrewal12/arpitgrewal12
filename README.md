### 2. [Body Activity Monitor](https://github.com/arpitgrewal12/BodyActivityMonitor)  
**Description:** Tracks and analyzes body movement and activity patterns to provide actionable health insights.  
**Tech Stack:** Python, Qt, Pandas, Matplotlib  
**Highlights:**  
- Real-time monitoring and logging of activity data.  
- Data visualization for activity trends and patterns.  
- Designed modular architecture for easy feature extension.

**Description:** Predicts COVID-19 case trends using historical data and machine learning models.  
**Tech Stack:** Python, Jupyter Notebook, Pandas, NumPy, Scikit-Learn, Matplotlib  
**Highlights:**  
- End-to-end pipeline from data cleaning to predictive modeling.  
- Visualization of trends for actionable insights.  
- Evaluated multiple models and selected the most accurate for prediction.
